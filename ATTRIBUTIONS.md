# Attributions / References

This project draws on publicly available reference implementations and design
documentation for **structure, proportions and timing only**. No source code was
copied and no third-party assets (images, fonts, icons, audio) are redistributed
except for npm packages listed in `package.json`, which keep their own licenses.

## Apple / iOS

- **No Apple assets, trademarks, SF Symbols, San Francisco fonts, or Apple logo
  imagery are used.**
- App icon glyphs are [lucide-react](https://github.com/lucide-icons/lucide)
  (ISC) and [react-icons](https://github.com/react-icons/react-icons) (MIT).
- The icon tiles are generated gradients and shapes drawn in code.
- PWA icons are generated by `scripts/generate-icons.mjs` (original artwork).
- Text uses `-apple-system, BlinkMacSystemFont` first (when available) and falls
  back to [Inter](https://github.com/rsms/inter) (SIL OFL 1.1) via
  `@fontsource-variable/inter`.

## Documentation consulted for values

| Source | Used for |
| --- | --- |
| [motion.dev — Layout & shared layout animations](https://motion.dev/docs/react-layout-animations) (MIT docs) | `layoutId` shared-element transitions for the app open/close zoom; that `borderRadius` participates in layout animations. |
| [Svelte playground — "iOS Home Screen"](https://svelte.dev/playground/5146c8e03a2847f6a108484dc4a31ad7) (MIT) | Dock glass recipe `backdrop-filter: saturate(180%) blur(20px)`. |
| [squircle.js.org](https://squircle.js.org/) and Figma's "corner smoothing" documentation | The `border-radius: 22.37%` approximation of the iOS squircle (continuous corner). |
| [Apple WWDC24 — "Enhance your UI animations and transitions"](https://developer.apple.com/videos/play/wwdc2024/10145/) | The *behaviour* of the iOS zoom transition (public session video; no assets used). |

### Values used in `src/styles/tokens.css` / `src/os/metrics.ts`

| Metric | Value used |
| --- | --- |
| App icon corner radius | `22.37%` of the icon edge |
| App icon size / dock icon size | `60px` / `56px` |
| Dock backdrop | `saturate(180%) blur(20px)` |
| Dock background | `rgba(255,255,255,.62)` light / `rgba(30,30,32,.62)` dark |
| Dynamic Island (collapsed) | `126 × 37 px`, top `11px`, full pill |
| Dynamic Island (expanded) | `260 × 46 px` |
| Status bar height | `54px` (island-era iPhones) |
| Home indicator | `140 × 5 px`, radius `2.5px`, bottom `8px` |
| App open/close spring | `stiffness 300, damping 30, mass 0.8` |
| Device aspect (desktop frame) | `430 × 931` ≈ `9 : 19.5` |

All of these were measured/approximated from public screenshots and design
write-ups, then re-implemented from scratch.
